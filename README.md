# 🟢 Ovoo — WhatsApp Server

The WhatsApp server component of the Ovoo platform, handling connections, message routing, and multi-device sessions.

## Features

- **Multi-device Sessions** — manage multiple WhatsApp connections
- **Message Routing** — inbound/outbound message handling
- **Version Management** — versioned deployment (v2.5)

## Setup

```bash
npm install
cp .env.example .env
npm start
```
